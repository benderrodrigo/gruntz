# GRUNTZ (unofficial web version)

An unofficial fan implementation of the *GRUNTZ* board game for personal play:
play against an AI (Easy, Normal, Hard) or pass and play, first to 3 or 5 Victory Stars.
Works offline and installs as an app.

**Play:** https://benderrodrigo.github.io/gruntz/

GRUNTZ is published by [Allplay](https://www.allplay.com/board-games/gruntz). This project is not
affiliated with or endorsed by the publisher; buy the game and read the official rules.
All artwork here is original (hand-drawn SVG); no publisher artwork is included.

Install: open the link in Chrome on Android and choose *Install app* (or *Add to Home screen*)
from the menu; on a laptop use the install icon in the Edge or Chrome address bar.

Game statistics are stored only in your own browser (localStorage).
